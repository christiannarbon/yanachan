Yana-chan 4K {{ .Chart.AppVersion }} is installed as {{ include "yana.fullname" . }} in {{ .Release.Namespace }} ({{ .Values.auth.mode }} mode).
{{- if include "yana.serverMode" . }}

Users sign in with GitHub at {{ .Values.auth.publicURL }}
The OAuth App's callback URL must be exactly:

  {{ .Values.auth.publicURL | trimSuffix "/" }}/api/auth/callback

Sessions are stored in Redis/Valkey at {{ .Values.auth.redis.url }}. The pod stays
NotReady (/api/ready) until it can reach it.

The pod reads keys from the Secret {{ include "yana.secretName" . }}. If it is not
there yet, the pod waits in CreateContainerConfigError until it is:

  kubectl -n {{ .Release.Namespace }} create secret generic {{ include "yana.secretName" . }} \
    --from-literal={{ .Values.auth.secretKeys.clientSecret }}=<client-secret> \
    --from-literal={{ .Values.auth.secretKeys.sessionKeys }}="$(head -c32 /dev/urandom | base64)" \
    --from-literal={{ .Values.auth.secretKeys.redisPassword }}=<redis-password>

Who may sign in:{{ with .Values.auth.allowedOrgs }} members of {{ join ", " . }}.{{ end }}{{ with .Values.auth.allowedUsers }} users {{ join ", " . }}.{{ end }}{{ if .Values.auth.allowAnyUser }} ANY GitHub user (auth.allowAnyUser=true).{{ end }}

Until an Ingress or HTTPRoute exists, try it through a port-forward; this only
works when auth.publicURL is http://localhost:19080:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "yana.fullname" . }} 19080:{{ .Values.service.port }}
{{- else }}

Local mode has no login of its own: anything that can reach it is signed in as
whoever stored the GitHub token. Reach it only through a port-forward:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "yana.fullname" . }} 19080:{{ .Values.service.port }}
  open http://localhost:19080

Sign in with the OAuth device flow (needs auth.clientId or the {{ .Values.auth.secretKeys.clientId }} key in the
{{ include "yana.secretName" . }} Secret), or put a token under {{ .Values.auth.secretKeys.token }}:

  kubectl -n {{ .Release.Namespace }} create secret generic {{ include "yana.secretName" . }} \
    --from-literal={{ .Values.auth.secretKeys.token }}=<token> --from-literal={{ .Values.auth.secretKeys.clientId }}=<client-id>
  kubectl -n {{ .Release.Namespace }} rollout restart deploy/{{ include "yana.fullname" . }}

The state volume {{ include "yana.claimName" . }} is kept on helm uninstall. Delete it yourself
to forget the stored session and settings.
{{- end }}
